Installing mysql within a docker container:
installation instructions reference: https://hevodata.com/learn/docker-mysql/#t4

1. Pull the image from docker hub: docker pull mysql/mysql-server:latest
2. Run the docker image: docker run -p 3306:3306 -d --name own-sql mysql/mysql-server:latest
3. Check whether the docker container is running or not: docker ps

Following command grants access to all the databases and tables in the server to the specified user
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%';

See the privileges for the user 
SHOW GRANTS FOR 'root'@'%';
